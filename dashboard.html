Gestión de roles

Los roles se guardan en Supabase Auth y se aplican de inmediato en la interfaz. Para que las restricciones de base de datos (RLS) también respeten el nuevo rol, la persona debe cerrar sesión y volver a iniciarla una vez.
Debe ser un usuario que ya exista en Supabase Auth (créalo primero desde el dashboard de Supabase si aún no existe).
Asignar roles a otros usuarios requiere permisos de administrador en Supabase (service_role), que este panel no incluye por seguridad. Usa el botón de abajo para generar el comando SQL exacto y ejecútalo tú mismo en el SQL Editor de Supabase.
